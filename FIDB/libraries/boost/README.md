# Generated Boost FID Libraries

This directory contains one packed `.fidb` per Boost 1.86.0 component. Each artifact is emitted by the original Ghidra `FidFileManager` and `FidService` APIs from object files extracted from the matching upstream static `.lib`; no FID bytes are hand-authored. Component reports and consumer tests are linked from [`../../reports/boost/`](../../reports/boost/) and [`../../tests/run_boost.py`](../../tests/run_boost.py).
