# Verification Reports

The files in this directory are generated by the pipeline in [`../README.md`](../README.md): [`library_analysis.json`](library_analysis.json), [`fidb_generation.json`](fidb_generation.json), [`fidb_verification.json`](fidb_verification.json), and the human-readable [`fidb_verification.md`](fidb_verification.md). They record concrete Ghidra version, language/compiler, ingestion counts, FID metadata, direct matches, analyzer markup, and negative-control evidence.

Reports are regenerated by `python FIDB\tests\zlib_detection\run_test.py --force` and are not inputs to the FID implementation.

Boost reports are regenerated by `python FIDB\tests\run_boost.py --force`; [`boost/summary.md`](boost/summary.md) summarizes all eight component tests and each component directory contains the corresponding machine-readable reports.
