# End-to-End Integration

[`end_to_end_tests.cppm`](end_to_end_tests.cppm) uses [`services/analyzers/tests/data/test_analyzers_integration.exe`](../../services/analyzers/tests/data/test_analyzers_integration.exe) as the primary executable fixture. It opens a project through the native facade, loads PE state and exported function seeds, decodes instruction bodies through the Sleigh service, runs scheduler-backed analysis, queries the current projection, submits two `Task<Result<Decompilation>>` operations, and verifies the durable SQLite rows after project shutdown.

The test writes [`full_pipeline_report.md`](../../build/test-reports/full_pipeline_report.md), retains the inspected project at [`project/projection.sqlite`](../../build/test-reports/project/projection.sqlite), and compares the generated Markdown byte-for-byte with the checked-in [`FullPeRuntimePipelineProducesProjectionAndReport.md`](reports/FullPeRuntimePipelineProducesProjectionAndReport.md). The writer uses canonical LF newlines. If the generated report changes, inspect the diff for a behavioral regression before updating the golden file.
