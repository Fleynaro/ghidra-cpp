# End-to-End Integration

[`end_to_end_tests.cppm`](end_to_end_tests.cppm) uses [`services/analyzers/tests/data/test_analyzers_integration.exe`](../../services/analyzers/tests/data/test_analyzers_integration.exe) as the primary executable fixture. It opens a project through the native facade, loads PE state and exported function seeds, decodes instruction bodies through the Sleigh service, runs scheduler-backed analysis, queries the current projection, and submits a stable-random sample of up to 10 `Task<Result<Decompilation>>` operations.

[`report_generator.cppm`](report_generator.cppm) owns the shared report structure, SQLite extraction, deterministic seed/sampling, limits, signatures, variables, bytes, instruction metadata, regions, symbols, event payloads, references, data objects, control flow, diagnostics, and decompilation source. The current limits are 50 functions, 10 decompilations, 1000 decoded instructions, 200 SQLite instruction rows, 100 event records, 100 characters per text cell, and 10000 characters per decompilation artifact.

The test writes [`full_pipeline_report.md`](../../build/test-reports/full_pipeline_report.md), retains the inspected project at [`project/projection.sqlite`](../../build/test-reports/project/projection.sqlite), and compares the generated Markdown byte-for-byte with the checked-in [`FullPeRuntimePipelineProducesProjectionAndReport.md`](reports/FullPeRuntimePipelineProducesProjectionAndReport.md). The writer uses canonical LF newlines and removes trailing whitespace. If the generated report changes, inspect the diff for a behavioral regression before updating the golden file.
