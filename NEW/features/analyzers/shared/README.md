# Shared Analyzer Runtime

This module owns the common analysis model and event-driven scheduler used by every analyzer submodule. The C++23 module interface and implementation are combined in [`src/analyzer.cppm`](src/analyzer.cppm); [`CMakeLists.txt`](CMakeLists.txt) contributes it to `NewGhidra::Analyzer`. Shared test-only helpers are in [`test_support/`](test_support/), including the [`analyzer_test_support.cppm`](test_support/analyzer_test_support.cppm) module and Python fixture utilities. Feature-specific implementations are sibling directories under [`../`](../), and their tests and fixture data remain isolated from this shared runtime.
