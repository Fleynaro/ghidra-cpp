# Analyzer Name
Apply Data Archives

## Purpose
Exercise application of a matching function signature from a user-selected built-in data-type archive.

## Original Ghidra Implementation
`Ghidra/Features/Base/src/main/java/ghidra/app/plugin/core/analysis/ApplyDataArchiveAnalyzer.java`.

## Test Scenario
The exported CRT-free `memcpy` candidate is analyzed with `generic_clib_64.gdt`; the script compares signatures and source types before and after analysis.

## Why This C++ Code Was Chosen
An exported function with the archive's stable name tests real symbol matching without linking the Windows CRT.

## Required Compiler Options
MSVC x64 and the Windows linker as invoked by `build.bat`.

## Required Auxiliary Files
The installed `Ghidra/Features/Base/data/typeinfo/generic/generic_clib_64.gdt` archive and `TEST/run_ghidra_python.bat` are required in addition to the generated PE.

## Ghidra Analysis Options
Set `Archive Chooser` to `generic_clib_64.gdt`, enable `Apply Data Archives`, and disable unrelated boolean analyzers.

## Expected Results
When the archive contains `memcpy`, its matching signature is applied; otherwise the report records that no matching change was observed.

## Generated Markdown
`test_apply_data_archives.md` is generated from the reopened program by `run_ghidra.py`.

## Notes / Limitations
Archive contents are installation/version dependent, and the fixture does not test runtime `memcpy` behavior. The existing sections below retain reproduction details.

## Behavior

This fixture exercises `ApplyDataArchiveAnalyzer`'s user-selected built-in archive path and the application of archive function signatures to a matching program symbol. The harness explicitly sets `Archive Chooser` to `generic_clib_64.gdt`, disables bookmark creation, and reports final function signatures and source types.

## Dependencies

- MSVC x64 tools and the Windows linker are required by [`build.bat`](build.bat).
- PyGhidra must be launched through [`../../../../TEST/run_ghidra_python.bat`](../../../../TEST/run_ghidra_python.bat).
- The installed Ghidra distribution must contain `Ghidra/Features/Base/data/typeinfo/generic/generic_clib_64.gdt`. This is an analyzer input, not a fixture-local auxiliary file, because archive paths are installation-specific.

## Limitations

Archive contents and matching signatures are versioned Ghidra data. If the installed archive does not contain `memcpy`, the analyzer still runs but produces no matching signature change; the generated report records that observation. The executable contains no CRT and therefore is not a runtime test of `memcpy`.

## Reproduction

Run `build.bat` in this directory. From the repository root, run `TEST\run_ghidra_python.bat NEW\features\analyzer\test_data\apply_data_archives\run_ghidra.py`.
