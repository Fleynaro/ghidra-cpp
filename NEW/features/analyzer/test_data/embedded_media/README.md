# Analyzer Name
Embedded Media

## Purpose
Exercise signature-based discovery and data-type creation for embedded media payloads in loaded memory.

## Original Ghidra Implementation
`Ghidra/Features/Base/src/main/java/ghidra/app/plugin/core/analysis/EmbeddedMediaAnalyzer.java`.

## Test Scenario
The PE contains real minimal GIF, PNG, JPEG, WAVE, MIDI, AU, and AIFF payloads; the script extracts created data types and analysis bookmarks.

## Why This C++ Code Was Chosen
Read-only arrays with real container structure test the analyzer's byte patterns and `CreateDataCmd` behavior without marker-only bytes.

## Required Compiler Options
MSVC x64 and the linker as invoked by `build.bat`.

## Required Auxiliary Files
The PE loader, `TEST/run_ghidra_python.bat`, and generated executable are required; no external media database is used.

## Ghidra Analysis Options
Enable only `Embedded Media` and leave `Create Analysis Bookmarks` enabled.

## Expected Results
Successful payloads should receive matching data types and one `Embedded Media` bookmark each; the report records only observed results.

## Generated Markdown
`test_embedded_media.md` is generated by `run_ghidra.py` from image-relative program state.

## Notes / Limitations
Creation can fail for an installed data-type definition or overlapping bytes, and addresses vary by linker layout. The existing sections below retain reproduction details.

This directory is an MSVC x64 PE fixture for Ghidra's `Embedded Media` analyzer.
The executable contains real, self-contained signatures for PNG, GIF, JPEG, WAVE,
MIDI, AU, and AIFF data in a loaded read-only PE section. The generated
[`test_embedded_media.md`](test_embedded_media.md) records the data types and
analysis bookmarks actually created by Ghidra.

## Navigation

- [`test_embedded_media.cpp`](test_embedded_media.cpp) embeds the media payloads and references each one from the entry point so the linker retains them.
- [`build.bat`](build.bat) builds a deterministic CRT-free MSVC x64 executable.
- [`run_ghidra.py`](run_ghidra.py) imports the PE, reopens it with `project.openProgram(...)`, enables only `Embedded Media`, runs analysis, and extracts a stable offset-based report.
- [`test_embedded_media.exe`](test_embedded_media.exe) is the generated PE input when the local MSVC toolchain is available.
- [`test_embedded_media.md`](test_embedded_media.md) is the generated behavioral report when PyGhidra is available.
- [`../README.md`](../README.md) describes the analyzer fixture collection.

## Reproduction

Run `build.bat` from this directory, then run
`TEST\\run_ghidra_python.bat NEW\\features\\analyzer\\test_data\\embedded_media\\run_ghidra.py`
from the repository root. The script accepts an optional executable and report
path.

The analyzer searches loaded and initialized memory, applies the corresponding
data type only when creation succeeds, and creates an `Embedded Media` analysis
bookmark by default. The script disables every boolean analysis option except
that analyzer and leaves no unrelated analysis responsible for the report.
