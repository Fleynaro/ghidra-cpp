# Analyzer Name
Call-Fixup Installer

## Purpose
Exercise compiler-spec call-fixup installation and caller flow repair for the security-cookie target.

## Original Ghidra Implementation
`Ghidra/Features/Base/src/main/java/ghidra/app/plugin/core/disassembler/CallFixupAnalyzer.java` and its user-visible `Call-Fixup Installer` registration in `CallFixupChangeAnalyzer.java`.

## Test Scenario
The exported `__security_check_cookie` symbol is analyzed and the script extracts installed fixup names and caller flow state.

## Why This C++ Code Was Chosen
The exact compiler-spec target name gives the analyzer a real discoverable function without CRT imports or injected fixup records.

## Required Compiler Options
MSVC x64 and the linker as invoked by `build.bat`.

## Required Auxiliary Files
The x86-64 Windows compiler specification containing `security_check_cookie` and `TEST/run_ghidra_python.bat` are required.

## Ghidra Analysis Options
Enable `Call-Fixup Installer` and disable unrelated boolean analyzers.

## Expected Results
The target receives the compiler-spec fixup when its name matches, and the report records the resulting caller flow state.

## Generated Markdown
`test_call_fixup_installer.md` is generated by `run_ghidra.py` from the analyzed program.

## Notes / Limitations
Fixup payloads and exact flow depend on the installed compiler specification. The existing sections below retain reproduction details.

## Behavior

The fixture targets the `security_check_cookie` call-fixup declared in `Ghidra/Processors/x86/data/languages/x86-64-win.cspec`. It verifies the observable mapping from the function name to `security_check_cookie` and records callers whose flow state changes.

## Dependencies

- MSVC x64 tools and the Windows linker are required by [`build.bat`](build.bat).
- PyGhidra must be launched through [`../../../../TEST/run_ghidra_python.bat`](../../../../TEST/run_ghidra_python.bat).
- The imported language must select the x86-64 Windows compiler specification containing the target. No auxiliary fixture file is required.

## Limitations

The installer only applies a fixup when the imported function name exactly matches a compiler-spec target (including its supported underscore fallbacks). Compiler-spec changes can alter the payload or whether the call is considered fall-through. The report records the installed result rather than asserting a fixed p-code body.

## Reproduction

Run `build.bat` in this directory. From the repository root, run `TEST\run_ghidra_python.bat NEW\features\analyzer\test_data\call_fixup_installer\run_ghidra.py`.
