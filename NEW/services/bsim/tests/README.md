# BSim Tests

`bsim_tests.cppm` covers duplicate-preserving TF construction,
cosine/significance behavior, feature-result validation, resource loading, and
the fixture target. `bsim_similarity_integration_tests.cppm` runs the real
PE Loader -> Sleigh -> native Decompiler -> BSim pipeline, checks semantic
ranking, and differentially compares twelve cosine pairs against the scalar
oracle generated by [`data/run_ghidra.py`](data/run_ghidra.py).

The fixture source and reproducible MSVC wrapper are under [`data/`](data/).

The test target is registered by [`CMakeLists.txt`](CMakeLists.txt) and links
the public `ReCode::Bsim` service contract plus Google Test. The native test
does not parse Markdown at runtime; the final scalar values are intentionally
reviewable in [`data/bsim_fixture.md`](data/bsim_fixture.md) and hardcoded in
the differential test. Run it with `NEW\build.bat bsim` or
`ctest --test-dir NEW\build -R bsim`.
