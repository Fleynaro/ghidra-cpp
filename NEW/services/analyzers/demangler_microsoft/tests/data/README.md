# Analyzer Name
Microsoft Demangler

## Purpose
Exercise parsing and application of genuine MSVC decorated C++ symbols.

## Original Ghidra Implementation
`Ghidra/Features/MicrosoftDemangler/src/main/java/ghidra/app/plugin/core/analysis/MicrosoftDemanglerAnalyzer.java`, using `AbstractDemanglerAnalyzer.java` and `MicrosoftDemangler.java`.

## Test Scenario
Exported namespace/class methods are demangled while a C-linkage symbol remains a negative control; the script extracts final symbol names and signatures.

## Why This C++ Code Was Chosen
Real namespace, instance, and static methods produce decorated exports without PDB files or an external demangler.

## Required Compiler Options
MSVC x64 and the linker as invoked by `build.bat`; no-inline and volatile state retain the methods.

## Required Auxiliary Files
The Microsoft Demangler feature, PE loader/disassembler, and `TEST/run_ghidra_python.bat` are required.

## Ghidra Analysis Options
Enable only `Demangler Microsoft`, with signature application configured by the script.

## Expected Results
Decorated symbols should receive readable demangled labels/signatures; the C-linkage symbol should not be reported as a demangler discovery.

## Generated Markdown
`test_demangler_microsoft.md` is generated by `run_ghidra.py`.

## Notes / Limitations
Decorated spellings and signature rendering are compiler/Ghidra-version dependent. The existing sections below retain reproduction details.

## Navigation

- [`test_demangler_microsoft.cpp`](test_demangler_microsoft.cpp) defines exported C++ namespace/class methods with genuine MSVC decorated names.
- [`build.bat`](build.bat) builds the deterministic CRT-free MSVC x64 PE.
- [`run_ghidra.py`](run_ghidra.py) prepares functions, enables Demangler Microsoft, and extracts mangled-to-demangled facts.

## Fixture Design

The class contains an instance method and a static method in a namespace. `__declspec(dllexport)` puts their actual decorated names into the PE export table, while noinline/volatile use retains the code. A C-linkage entry function is a negative non-mangled symbol.

## Ghidra Java Contract

The target is [`Ghidra/Features/MicrosoftDemangler/src/main/java/ghidra/app/plugin/core/analysis/MicrosoftDemanglerAnalyzer.java`](../../../../../Ghidra/Features/MicrosoftDemangler/src/main/java/ghidra/app/plugin/core/analysis/MicrosoftDemanglerAnalyzer.java), built on [`AbstractDemanglerAnalyzer.java`](../../../../../Ghidra/Features/Base/src/main/java/ghidra/app/plugin/core/analysis/AbstractDemanglerAnalyzer.java). The implementation filters default-source symbols, demangles eligible global symbols, and applies the resulting labels/signatures through [`MicrosoftDemangler.java`](../../../../../Ghidra/Features/MicrosoftDemangler/src/main/java/ghidra/app/util/demangler/microsoft/MicrosoftDemangler.java). The report reads the actual post-analysis symbols and signatures.

## Dependencies

The fixture requires MSVC x64 decorated-name emission. The script requires the repository PyGhidra wrapper, PE loader, disassembler, MicrosoftDemangler feature, and its Java dependencies. It does not use PDB files or an external demangler executable.

## Limitations

Decorated spelling and signature rendering are compiler/Ghidra-version outputs. The script does not assume exact addresses or invent a demangled name if Ghidra rejects a symbol. The C-linkage entry is retained only as a negative case.

## Reproduction

Run `build.bat`, then from the repository root run `TEST\run_ghidra_python.bat \features\\analyzers\demangler_microsoft\\tests\\data\\\\run_ghidra.py`. Optional executable/report arguments are accepted.

## Generated Artifacts

MSVC generates `test_demangler_microsoft.exe`; PyGhidra generates `test_demangler_microsoft.md`. These files are not hand-written substitutes for unavailable tool output.

## Validation

Validation completed with MSVC 2022 x64 compilation/linking, project save/reopen through `project.openProgram(...)`, target-only analysis, and before/after symbol inspection. The generated report contains two decorated methods, their demangled signatures, and explicit Delta rows.
