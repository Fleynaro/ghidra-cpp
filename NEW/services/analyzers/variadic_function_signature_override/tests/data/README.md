# Analyzer Name
Variadic Function Signature Override

## Purpose
Exercise format-string inference that expands a variadic call-site signature beyond its fixed parameter.

## Original Ghidra Implementation
`Ghidra/Features/DecompilerDependent/src/main/java/ghidra/app/plugin/core/string/variadic/FormatStringAnalyzer.java`.

## Test Scenario
The PDB supplies only the fixed format pointer while `%d` and `%s` describe two call arguments; the script snapshots call-site signatures, override bookmarks, and P-code references before and after target analysis, then emits keyed deltas.

## Why This C++ Code Was Chosen
A real local variadic function, live format string, and observable integer/string arguments test inference rather than merely PDB signature import.

## Required Compiler Options
MSVC x64 with PDB generation as invoked by `build.bat`.

## Required Auxiliary Files
The matching PDB, PDB Universal and ASCII Strings dependencies, Decompiler feature, and
`TEST/run_ghidra_python.bat` are required.

## Ghidra Analysis Options
Enable `Variadic Function Signature Override` and its explicit `PDB Universal` and
`ASCII Strings` dependencies only.

## Expected Results
The analyzed call should gain definitions for the `%d` and `%s` arguments; the report compares actual P-code call inputs and persisted override evidence.

## Generated Markdown
`test_variadic_function_signature_override.md` is generated by `run_ghidra.py`.

## Notes / Limitations

The Universal PDB reader can preserve the fixed `const char *` parameter while omitting the
MSVC varargs flag for a local CRT-free definition. The runner restores only that missing
signature flag transactionally before enabling `Format String`; parameter and return types
remain PDB-derived, and all added call parameters are still extracted from the analyzer's
post-analysis state.

The current Ghidra build may produce no `Function Signature Override` bookmark for this
CRT-free local definition even though the real analyzer runs and the P-code call is recorded.
That zero-row result is preserved in the golden report rather than replaced with invented
parameters; a CRT-import variant can be added when a stable MSVC CRT import environment is
available.
PDB matching, decompiler call modeling, and supported format specifiers are version dependent. The existing sections below retain reproduction details.

This directory contains a CRT-free MSVC x64 PE that calls a PDB-described local
`fixture_printf` variadic function with a real format string. The call has one fixed
format-pointer parameter in the local PDB signature and two additional arguments
described only by `%d` and `%s`.
The generated report proves that Ghidra's `Variadic Function Signature Override` analyzer
expanded the call-site signature after import; it does not merely report the PDB type.
