# Analyzer Name
Condense Filler Bytes

## Purpose
Exercise selection of the most frequent undefined filler byte and replacement with alignment data.

## Original Ghidra Implementation
`Ghidra/Features/Base/src/main/java/ghidra/app/analyzers/CondenseFillerBytesAnalyzer.java`.

## Test Scenario
Ordered no-inline functions create linker boundaries; `run_ghidra.py` runs Auto mode and extracts alignment ranges and adjacent bytes.

## Why This C++ Code Was Chosen
Separate code-section functions provide real linker padding samples while avoiding assumptions about a particular fill byte.

## Required Compiler Options
MSVC x64 and the linker as invoked by `build.bat`; function ordering and retention are required for useful samples.

## Required Auxiliary Files
`TEST/run_ghidra_python.bat` and the generated executable are required; no external fixture database is needed.

## Ghidra Analysis Options
Enable only `Condense Filler Bytes` and select Auto filler mode.

## Expected Results
Matching undefined runs may become `AlignmentDataType`; the report records observed alignment data rather than a fixed range.

## Generated Markdown
`test_condense_filler_bytes.md` is generated by `run_ghidra.py`.

## Notes / Limitations
MSVC linker padding and function ordering are environment-dependent, and there may be no eligible run. The existing sections below retain reproduction details.

## Behavior

This fixture exercises the analyzer's most-frequent-filler selection and replacement of matching undefined runs with `AlignmentDataType`. The report records final alignment ranges and their lengths.

## Dependencies

- MSVC x64 tools and the Windows linker are required by [`build.bat`](build.bat).
- PyGhidra must be launched through [`../../../../TEST/run_ghidra_python.bat`](../../../../TEST/run_ghidra_python.bat).

## Limitations

Linker padding bytes, function ordering, and alignment ranges are implementation details of the installed MSVC linker. The fixture deliberately reports observed ranges and does not promise fixed addresses or a fixed fill byte. If the linker emits no undefined run after a function, the authoritative analyzer has no work to perform.

## Reproduction

Run `build.bat` in this directory. From the repository root, run `TEST\run_ghidra_python.bat \features\\analyzers\condense_filler_bytes\\tests\\data\\\\run_ghidra.py`.
